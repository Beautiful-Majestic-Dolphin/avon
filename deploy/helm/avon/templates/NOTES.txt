GETTING STARTED:
----------------

1. Wait for all pods to be ready:
   kubectl get pods -n {{ .Release.Namespace }} -l "app.kubernetes.io/instance={{ .Release.Name }}" -w

2. Check service status:
   kubectl get svc -n {{ .Release.Namespace }} -l "app.kubernetes.io/instance={{ .Release.Name }}"

3. View logs for a specific service:
   kubectl logs -n {{ .Release.Namespace }} -l "app.kubernetes.io/component=gateway" -f
   kubectl logs -n {{ .Release.Namespace }} -l "app.kubernetes.io/component=auth" -f
   kubectl logs -n {{ .Release.Namespace }} -l "app.kubernetes.io/component=admin-api" -f
